# TokoKita

TokoKita adalah aplikasi web berbasis Laravel dan PostgreSQL.

## Teknologi

- Laravel
- PHP
- PostgreSQL
- Git
- GitHub

## Database

Aplikasi menggunakan PostgreSQL sebagai database.

Database:
- Nama: `tokokita`
- Driver: `pgsql`

## Development

Project ini dikembangkan menggunakan framework Laravel.
